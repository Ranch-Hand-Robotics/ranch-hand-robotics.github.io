# Ranch Hand Robotics, LLC

Practical, open-source tools for building robots that help on farms, in fields, and through forests.

Ranch Hand Robotics is a solo-founder venture based in Washington State, USA, started in 2024. The free robot developer extensions for VS Code and Cursor help with debugging, robot modeling, and project setup. The roadmap explores outdoor robots, off-grid communications, and portable field control stations.

## Explore the projects

- [Website](https://ranchhandrobotics.com): developer tools and project teasers.
- [Roadmap](https://ranchhandrobotics.com/comingsoon.html): outdoor robot concepts and design goals, not ready-to-order products.
- [YouTube](https://www.youtube.com/@rh_robotics): follow the builds.
- [Discord](https://discord.gg/gBNNC3vbwY): share ideas and feedback.
